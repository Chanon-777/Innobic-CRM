# Innobic CRM

ต้นแบบ CRM สำหรับวางแผนเข้าพบแพทย์ ติดตามโอกาสขาย และดูยอดขายตามผลิตภัณฑ์ โรงพยาบาล แพทย์ และ Sales

## ทดลองใช้งานเว็บไซต์

ดาวน์โหลดหรือโคลนรีโพซิทอรี แล้วเปิด [index.html](./index.html) ในเบราว์เซอร์ เว็บไซต์เปิดพร้อมข้อมูลจำลอง 6 เดือนและใช้งานได้โดยไม่ต้องติดตั้งหรือเรียก API

1. เลือก **บันทึกและติดตาม CRM** เพื่อดูแดชบอร์ด ปฏิทินทีม และโอกาสขายตามขั้น
2. ใน **แผนเข้าพบ** เลือกนัดตามโรงพยาบาลและวอร์ด แล้วกด **บันทึกผล**
3. กด **บันทึกยอดขายจากการเข้าพบนี้** ระบุผลิตภัณฑ์และยอดขาย แล้วดูผลในแดชบอร์ดและรายงานผลิตภัณฑ์
4. กด **กลับไปยังข้อมูลของคุณ** เพื่อใช้ข้อมูลที่เก็บในเบราว์เซอร์ การแก้ไขข้อมูลจำลองจะหายเมื่อออกจากโหมดหรือรีเฟรช

ปฏิทินแสดงนัดของ Sales ทุกคนที่มีข้อมูลในเบราว์เซอร์เดียวกัน ชี้เมาส์หรือแตะวันที่มีนัดเพื่อดูรายละเอียด

## รัน Backend ต้นแบบ

ใช้ Node.js 24 แล้วรันจากโฟลเดอร์หลักของรีโพซิทอรี

```sh
node backend/innobic-crm-demo.mjs
```

API เปิดที่ `http://127.0.0.1:3010/api/v1` รองรับการค้นหาแพทย์ สร้างและแก้ไขร่าง ยืนยันผล และดูประวัติการเข้าพบ

ตัวอย่างค้นหาแพทย์ด้วย session จำลอง

```sh
curl -H "Cookie: crm_session=demo-a" http://127.0.0.1:3010/api/v1/hcps
```

รันชุดทดสอบ Backend

```sh
node backend/innobic-crm-demo-test.mjs
```

| ไฟล์ | รายละเอียด |
| --- | --- |
| [OpenAPI](./backend/innobic-crm-openapi.json) | สัญญา API สำหรับวงจรเข้าพบ |
| [PostgreSQL schema](./backend/innobic-crm-visit-schema.sql) | ร่างโครงสร้างฐานข้อมูล |

## สถานะการเชื่อมต่อ

หน้าเว็บและ Backend รันแยกกันในรุ่นนี้ หน้าเว็บเก็บข้อมูลในเบราว์เซอร์ ส่วน Backend เก็บข้อมูลจำลองในหน่วยความจำและรีเซ็ตเมื่อปิดโปรเซส ไฟล์ PostgreSQL เป็นร่างสำหรับพัฒนาต่อ หากต้องการเปิด API ออนไลน์ ต้องนำ Backend ไปติดตั้งบนบริการโฮสต์
